About This Project & How to Run It

This project is a suite of client-side tools that interact with the Twitch API. To use them, you must authenticate with your Twitch account. Your credentials are handled securely on the client-side and are not stored anywhere.

Running Locally

Due to web security policies (CORS), you cannot simply open the `.html` files in your browser. You need to run a local web server.

  1. Ensure you have Python installed on your system.
  2. Open a terminal or command prompt in the project's root directory.
  3. Run the command: python -m http.server 8000
  4. Open your web browser and navigate to http://localhost:8000.

This will allow the application to make API calls to Twitch correctly.
